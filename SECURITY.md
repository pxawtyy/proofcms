# Security policy

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability in ProofCMS.
Use GitHub's private vulnerability reporting feature for this repository and
include the affected version, reproduction steps, impact, and any proposed fix.

## Scope

Reports about ProofCMS itself are in scope. Results produced against third-party
CMS installations should be reported to the affected vendor or project through
its coordinated disclosure process.
